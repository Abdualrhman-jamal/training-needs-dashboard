# لوحة تحليل الاحتياج التدريبي

صفحة عربية لتحليل ملفات Excel الخاصة بحصر الاحتياج التدريبي.

## المزايا

- رفع ملف Excel واحد أو عدة ملفات في نفس الوقت.
- دمج جميع التبويبات والفروع والإدارات في تقرير واحد.
- تحليل نوع التطوير مثل: دورة تدريبية، تجارب/زيارات خارجية، تدريب أثناء العمل، تعلم ذاتي، ورش عمل.
- تحليل نوع الاحتياج: سد فجوة، تطوير تشغيلي، متطلب نظامي وغيرها.
- مؤشرات رئيسية ورسوم بيانية.
- البحث والفلترة حسب الإدارة، نوع الاحتياج، نوع التطوير، الأولوية وحالة الاكتمال.
- جدول تفصيلي للموظفين والبرامج المقترحة.
- طباعة التقرير أو حفظه PDF من المتصفح.

## الخصوصية

ملفات Excel تتم قراءتها داخل متصفح المستخدم فقط. بيانات الموظفين لا يتم رفعها أو تخزينها داخل هذا المستودع.

## التشغيل

افتح `index.html` أو فعّل GitHub Pages للمستودع من Settings > Pages ثم اختر النشر من فرع `main` والمجلد `/root`.
